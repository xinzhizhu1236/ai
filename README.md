# ai
基于多 Agent 协同的全球化市场情报与战略推演系统
1. 项目解决的核心痛点
在当前的商业环境下，企业面临着严重的信息非对称与决策滞后问题：

信息过载与破碎化： 市场数据散落在社交媒体（用户真实声量）、新闻财报（企业动态）及电商评论（产品缺陷）中，人工收集耗时耗力且难以实时化。

分析维度单一： 传统 AI 工具仅能做简单的摘要，无法像资深分析师一样将“消费者痛点”与“竞品技术路线”跨维度关联。

决策链路断层： 从获取原始数据到生成可落地的 SWOT 战略报告，中间缺乏严密的逻辑推导链条，导致 AI 生成的建议流于表面。

2. 核心逻辑流与技术架构
本项目基于 LangGraph 构建了一个具备“感知-思考-决策”能力的 Multi-Agent 协作体系，核心逻辑如下：

多 Agent 协同机制：

Scout Agent（感知层）： 负责任务拆解，利用多路并发技术调用搜索 API 与定制化爬虫，获取异构数据并进行清洗。

Analyst Agent（认知层）： 接收 Scout 抓取的海量文本，通过 Long Context Window 提取关键特征，执行情感极性分析，识别出消费者未被满足的潜在需求。

Strategist Agent（决策层）： 汇总前序 Agent 的所有结构化输出。

长链推理（Long-chain Reasoning）：
系统不直接输出结论，而是采用 思维链（CoT） 框架。例如，在分析竞品时，Agent 会首先推理其专利布局背后的意图，再结合财报中的研发投入预测其产品路线图，最后对比我方优势。这种递归式的推理确保了最终生成的 SWOT 报告具有深度的商业洞察力。

状态化管理（Stateful Workflow）：
通过统一的 MarketState 维护上下文，确保 Agent 之间的数据传递是类型安全且可回溯的，极大地降低了长流程中的幻觉率。

3. 具体成果（示例量化）
效能提升： 将以往需要 3-5 天的行业深度调研缩短至 10 分钟 内完成。

决策深度： 能够识别出 85% 以上人工调研容易忽略的细分市场机会点。

Token 价值： 单次完整推演涉及多次模型往返（Round-trip）及大量长文本吞吐，单任务 Token 消耗约 2.5w-5w，对高配额 Token Plan 有强依赖性，具有极高的应用落地价值。
